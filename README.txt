KODUMATA – iOS 9.3.5 Safari jaoks kohandatud veebiversioon

Failid:
- index.html
- style.css
- app.js

See versioon kasutab JavaScriptis ES5 süntaksit (ei kasuta const/let, noolefunktsioone, mallisõnesid, Number.isInteger ega Array.includes) ning CSS-is ei kasuta CSS Grid'i, clamp() funktsiooni ega CSS-i muutujaid.

Funktsioonid:
- arvude vahemik 1–50 või 1–100;
- liitmise tulemus ei ületa valitud piiri;
- lahutamisel ei teki negatiivseid vastuseid;
- tehete arvu ja vastamisaja valik;
- pärast kolme vale arvulist vastust näidatakse õiget vastust ja minnakse järgmise tehte juurde;
- pärast aja lõppemist saab vastamist jätkata.

GitHubi uuendamine:
1. Ava GitHubis kodumata-veeb repository.
2. Asenda repository juurkaustas olevad index.html, style.css ja app.js selle ZIP-i vastavate failidega.
3. Salvesta muudatused Commit changes nupuga.
4. Oota, kuni GitHub Pages avaldab uue versiooni.

Märkus: see versioon on kirjutatud vanemate brauserite ühilduvust silmas pidades, kuid lõplik kontroll tuleb teha päris iPadis, kus töötab iOS 9.3.5 Safari.
